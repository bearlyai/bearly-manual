# Bearly Manual

The complete guide to using [Bearly](https://bearly.ai), one app for Claude, GPT, Gemini, Grok, and more: every setting and capability, how features connect, and step-by-step recipes that combine them. It's written for people, AI assistants, and agents.

This repository is a Markdown copy of the Manual published at **[bearly.ai/docs/manual](https://bearly.ai/docs/manual/)**, refreshed every day. bearly.ai is the source of truth.

## Files

- [`manual.md`](manual.md) is the index. Every page is listed with a one-sentence description of the job it answers.
- [`manual/`](manual/) has one Markdown file per page.
- [`manual-full.md`](manual-full.md) is the whole Manual in one file.

## Using it with an AI model or agent

Start with `manual.md`, pick the page whose description matches the task, and follow its steps. For workflows that chain several features, read `manual/combine/building-blocks.md` and the recipe pages. The same files are served live at `https://bearly.ai/docs/manual.md` and `https://bearly.ai/docs/manual-full.txt`.

## Questions and corrections

If something here differs from the app, the app is right. Tell us at support@bearly.ai, or with **Give Feedback** in the app's account menu.
